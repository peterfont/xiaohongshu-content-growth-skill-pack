# 小红书内容实验 Skill Pack v5

这版从“单篇内容实验”扩展到“产品推广完整系统”。

## 完整链路
产品 → 用户任务 → 账号定位 → 竞品对标 → 推广计划 → 选题 → 行为预测 → 内容架构 → 发布形态 → 视觉结构 → 文案生成 → 质检 → 发布 → 数据分析 → 策略学习

## v5 核心变化
- 产品号先回答“用户为什么关注”，再回答“我是谁”。
- 对标不是照抄，而是提取账号定位、任务库、标题结构和产品植入方式。
- 推广内容围绕用户任务组织，不围绕功能列表组织。
- 默认内容比例：20%问题 / 30%方法 / 30%工具场景 / 20%数据案例。
- 至少50%内容来自真实操作、真实数据或真实案例。
- 第一轮固定跑14天，不频繁换定位。
- 问题帖看评论率；方法帖看收藏率；数据帖看收藏+关注；工具帖看主页访问/私信/咨询。
