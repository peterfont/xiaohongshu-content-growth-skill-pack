# 当前账号实验规则（非行业通则）

这些规则来自当前账号的历史发布与复盘，只在当前账号/相近受众上继续验证，不视为全平台规律。

## 当前内容比例（v11以后）
- 40%：程序员身份 + AI / 赚钱 / 转型
- 30%：产品 / 找用户 / 做什么
- 20%：AI一人公司 / 商业方向
- 10%：第二层 / 第三层经营内容

## 当前已出现的有效信号

### H2：程序员身份 × AI变化 × 自身利益 × 认知反转
继续复现方向：
- 程序员未来最值钱的能力
- AI会写代码以后程序员还剩什么
- 程序员除了卖软件还能怎么赚钱
- 技术人的优势往哪里迁移

### H1/H2：AI + 具体行动选择
例如“一人用AI适合做什么生意”，继续验证。

### H1：路径打开型
“原以为只有A，原来还有B/C/D”，有收藏/关注潜力。

### H1负向：抽象商业机制直接做入口
信息差、经营系统、宏观套利逻辑等直接做标题入口目前点击偏弱。
策略：不否定正文价值，只降低其标题入口优先级。

### H1：深内容可以高收藏，但需要浅入口
若CTR低而收藏率高：保留正文，重做标题/封面/身份入口。

## 账号主线
当前长期主线优先围绕：
> 程序员 → AI → 独立开发 → 真实经营 → 一人公司

关注理由应尽量服务这条主线，不要每篇随机承诺新方向。

## 重要限制
以上不是行业统计，也不是永久真理。每次发布后都要通过 `performance-analyst` + `strategy-learner` 更新。
