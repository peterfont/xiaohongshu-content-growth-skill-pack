# 小红书策略学习

## 核心目标

把：

> “这篇数据不错”

变成：

> “在什么条件下，什么行为更可能发生？”

---

# 一、规则结构

每条规则必须包含：

- Rule ID
- 条件
- 预测
- 实际
- 样本
- 反例
- 样本数
- 置信度
- 适用范围
- 当前结论

---

# 二、置信度

### 低
1～2 个样本

### 中
3～5 个相似样本

### 较高
6～10 个相似样本

### 高
10+ 且跨主题重复

---

# 三、重点学习6类映射

## 1. 选题 → 用户行为
例如：
群体提问 → 评论

## 2. 标题 → 点击
例如：
明确问题 + 数字方法 → 点击

## 3. 正文结构 → 收藏/评论
例如：
步骤化 → 收藏
开放讨论 → 评论

## 4. 人设/系列 → 关注
例如：
真实过程 + 下一步 → 关注

## 5. 关键词 → 搜索
例如：
标题 + 前100字 + 正文语义 → 搜索流量

## 6. 案例 → 商业咨询
例如：
具体场景 + 结果 → 咨询

---

# 四、行为错配也要学习

例如：

预测收藏高，选题正确，
但正文没有判断标准，
最终收藏一般。

这不能更新为：

> “这个选题不收藏。”

而应该更新为：

> “选题具备收藏潜力，但内容结构未兑现。”

必须区分：

- 选题预测错
- 内容执行错
- 流量入口错
- 承接错

---

# 五、输出

【新增规则】

【已有规则更新】

【反例】

【仍不确定的问题】

【下一轮实验】
只选 1～3 个。

## 核心原则

> 样本少时只说“假设”。

> 不把相关性说成因果。

> 规则必须带适用条件。

> 失败样本同样重要。
