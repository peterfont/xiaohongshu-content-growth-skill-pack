# 小红书选题策划 v17

## 1. 选题、标题、正文严格分离
- 选题：内部研究问题，可以抽象。
- 标题：外部点击入口，必须具体、好懂、自我相关。
- 正文：兑现标题，用最短路径让用户从“为什么”到“原来如此”。

## 2. 用户层级
第一层：刚开始/未找到用户，核心“有没有人要？”
- A 身份利益型（当前入口优先级最高）
- B 行动选择型
- C 抽象认知型
第二层：已有反馈/少量成交，核心“为什么不买？”
第三层：稳定经营，核心“值不值得长期做？”

原则：认知可领先两层，内容入口最好只领先半层。

## 3. 选题证据等级
- V1 已验证母题
- V2 有需求证据
- V3 推导型
- V4 纯探索
优先用 V1/V2 做机制测试。

## 4. 假设等级
- H0：尚无验证
- H1：单次/初步信号
- H2：多个相似样本重复出现
- H3：跨主题、跨时间稳定复现
不得用单篇直接升级成稳定规律。

## 5. 母题与子题
母题承载长期认知主线；子题一次只验证一个角度。
同母题连续发布不等于同质化，前提是内容功能不同：观点/案例/搜索舆情/方法/数据/个人经历/路径比较。

## 6. 标题前置条件
候选标题必须：
- ≤20 字；默认 12–18 字；
- 优先“人 + 变化 + 利益/问题”；
- 优先现象句，少用抽象理论句；
- 不把内部选题原样复制成标题；
- 不把标题写成全文摘要。

抽象词警报：商业模式、信息差、经营系统、组织范式、生产关系、效率革命等。若必须用，先改成用户能立刻看到自己的入口。

## 7. 输出
【选题】【母题】【子题】【用户层级】【V等级】【H等级】【为什么值得验证】【是否需要 Research】【候选入口方向】
