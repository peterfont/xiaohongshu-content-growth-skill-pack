# 发布后数据诊断 v17

## 目标
内容生产负责生产；数据复盘负责学习。二者分开。

## 分析顺序
曝光 → CTR/点击 → 阅读深度/停留 → 收藏/评论/分享 → 关注 → 商业转化。

## 必须做“预测 vs 实际”
逐项比较发布前关于点击、停留、收藏、评论、关注的预测。

## 核心诊断
- CTR低 + 收藏率高：入口弱，正文可能强；优先换标题/封面/身份入口，保留正文。
- CTR高 + 收藏评论弱：标题成立，正文承诺兑现不足或内容过薄。
- CTR低 + 互动低：优先怀疑选题/入口。
- CTR高 + 收藏/涨粉高：高价值母题，优先拆母题树继续复现。
- 停留不错 + 收藏低：检查可复用性、具体度、结构。
- 收藏高 + 关注低：检查人设、系列感、关注理由、长期价值。
- 评论问题写了但评论低：检查是否真的有表达欲，而非只给了一个问题。

## 不允许
- 用全平台所谓固定“流量池等级”代替账号自己的基线分析。
- 用单篇绝对曝光给账号定段位。
- 相关性直接写成因果。

## 账号自身基线
优先比较：中位数、P25/P75/P90、相对基线倍率、高表现复制率，而不是套统一曝光阈值。
