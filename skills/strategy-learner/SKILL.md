# 策略学习与规则沉淀 v17

## 使命
发布 → 数据 → 比较预测与实际 → 找重复模式 → 区分随机与稳定 → 更新规则 → 下一轮使用。

## 规则格式
Rule ID / 条件 / 预测 / 实际 / 结论 / 样本数 / 置信度 / 反例 / 适用范围。

## 置信度
H0：未验证。
H1：单次或初步信号。
H2：多个相似样本重复。
H3：跨主题/跨时间稳定复现。

## 不允许
- 1 个样本宣布普遍规律。
- 忽略反例。
- 相关性冒充因果。
- 不同账号/人群无条件混合。
- 只因为绝对曝光高就宣布“模型形成”。

## 优先学习
- 选题 → 哪种行为
- 标题 → 点击
- 正文机制 → 停留/收藏/评论
- 路径打开 → 收藏/关注
- 人设/系列 → 关注
- 关键词 → 搜索
- 商业案例 → 咨询
- Research 素材密度/用户语言 → 内容效果

## 输出
【本次新增规则】【已有规则置信度变化】【反例】【下一轮最值得验证的1–3个假设】
