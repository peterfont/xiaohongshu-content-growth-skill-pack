# 小红书竞品对标 Skill

## 核心原则
不抄内容，抄赚钱结构；不抄标题字面，抄用户任务、内容机制和产品植入方式。

## 必拆维度
账号定位、昵称简介、九宫格视觉、置顶逻辑、高频标题模板、高频用户任务、产品出现位置、内容类型比例、发布节奏、评论钩子、转化承接。

## 高频标题结构
- 现场提问型：具体状态 + 数字/场景 + 正常吗？ → 评论/拉新
- “别只……”型：常见做法 + 不够 + 更好判断 → 收藏/信任
- “用这个……”型：具体任务 + 工具 + 结果 → 产品教育/转化
- “以前…后来…”型：旧做法 → 踩坑 → 新做法 → 真人感/信任
- “真正问题不是…”型：表面问题 → 深层问题 → 观点/专业判断

## 产品植入强度
弱30%：只说工作流；中40%：自然提产品；强30%：直接演示点击→采集→导出/下载。

## 核心模型
一个产品 × 多个真实用户任务 × 多种内容机制。

## 禁止
不直接复制竞品标题、正文、封面；不把竞品经验当平台官方规律；竞品只提供已被测试过的母题和结构，最终仍需自己的数据验证。

## 输出
竞品定位、高频任务、标题结构、植入方式、节奏、可复制机制、不可复制部分、迁移后的内容地图。
